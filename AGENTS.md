# Agents

## Regras de commit

- Toda alteração feita no código DEVE ser commitada e enviada (push) ao repositório remoto imediatamente após ser feita.
- Nunca deixar alterações pendentes sem commit ao final de cada tarefa.
- Mensagens de commit devem ser claras e descritivas em português.
- Sempre faça `git add .`, `git commit` e `git push` após cada modificação relevante.
- Antes de cada commit, verificar `git status` para garantir que apenas os arquivos desejados estão staged.
